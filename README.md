# diff-voyager.github.io

Landing page for [diff-voyager](https://github.com/diff-voyager/diff-voyager), published at <https://diff-voyager.github.io/>.

diff-voyager is an early-stage tool for comparing a website before and after a migration: visuals, SEO and communication.

## Development

The site is built by GitHub Pages with [Jekyll](https://jekyllrb.com/). Page chrome lives in `_layouts/default.html`, styles in `assets/css/style.css`, and site-wide values in `_config.yml`.

```sh
bundle install
bundle exec jekyll serve
```
